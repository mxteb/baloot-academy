# مدرسة البلوت | Baloot Academy

تطبيق ويب تعليمي عربي لتعلّم البلوت السعودي باللعب، مع تركيز خاص على الفرق بين **الصن** و**الحكم** والمشي الصحيح.

**اللعبة:** [mxteb.github.io/baloot-academy](https://mxteb.github.io/baloot-academy/)

## المزايا

- مسار من 10 محطات يشرح اللعب والورق واتباع النوع والقص والنقاط والشراء والمشاريع وحساب العقد.
- أسلوب شرح سعودي مباشر، مع موقف تطبيقي بعد كل قاعدة وتصحيح واضح للحركة المخالفة.
- مقارنة بصرية بين الصن والحكم، واختبار تفاعلي لترتيب الورق.
- 20 موقفًا تكتيكيًا بدرجات صعوبة وتلميحات وتحليل لأفضل حركة.
- توزيعة تدريب كاملة: تبدأ بخمس ورقات، تختار الصن أو الحكم أو تمرر، ثم تكمل اليد وتلعب الأكلات الثماني مع ثلاثة لاعبين آليين.
- نتيجة الجولة تعرض نقاط الأكلات، المشاريع المكتشفة، والفريق الذي وفّى بالعقد. حساب المزايدة والمشاريع مبسّط للتدريب؛ توجد اختلافات بين قواعد المجالس.
- محرك قواعد مستقل لاتباع النوع والقص والتدريج الإجباري وتحديد الفائز ونقاط الأكلة.
- أوراق SVG واقعية ومتناسقة.
- حفظ تقدم الدروس والنقاط على الجهاز.
- PWA قابل للتثبيت على Android وiPhone.
- دعم واجهة RTL والعمل الأساسي دون اتصال بعد أول زيارة.

## التشغيل محليًا

يتطلب Node.js 22.13 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية.

## الاختبارات

```bash
npm run test:rules
```

تشمل الاختبارات ترتيب الصن والحكم، اتباع النوع، القص، تحديد الفائز ونقاط الحكم.

## بنية المشروع

- `app/` الواجهة وتجربة PWA.
- `lib/baloot-engine.mjs` محرك القواعد الحتمي.
- `lib/scenarios.mjs` سيناريوهات التدريب المنظمة.
- `public/site.webmanifest` إعدادات تثبيت التطبيق.
- `public/sw.js` التخزين المؤقت والعمل دون اتصال.
- `tests/` اختبارات قواعد اللعبة.

## التقنية

React، TypeScript، Vinext، Tailwind CSS، وSVG Playing Cards.
